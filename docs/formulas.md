# Formulas in the engine

Every formula the engine computes (`js/engine/index.js`), generated from `FORMULAS` and `runChecks()`. 44 formulas; 179 of 179 worked examples reproduce.

## How to use

```js
import { FORMULAS, ALL_FORMULAS, runAll, runFormula, runChecks } from './js/engine/index.js';

runAll(person);                          // one result per formula (risk and value kinds)
runAll(person, { includeScores: true }); // also point scores without a probability
runAll(person, { includeMore: true });   // all 44; the default is the eight the pages show
runFormula('pooled-cohort-equations-pce', person);
runChecks();                             // re-computes the worked examples
```

`person` is `{ profile, labs }` as in `docs/interfaces.md`. Each result has `status` (computed, missing, not-applicable), `value`, `display`, `terms` (label, input, beta, x, contribution, or points), `equation`, `missing` (fields to ask for), `reason`, `source` and `notes`. The app reaches it through `ctx.runAll` (`js/engine/run.js`).

Coefficients, betas, means and baseline survival are in each `js/engine/formulas/<id>.js` (with table and page). Group details: [`brain-mortality.md`](formulas/brain-mortality.md), [`cancer.md`](formulas/cancer.md), [`cvd.md`](formulas/cvd.md), [`liver-copd.md`](formulas/liver-copd.md), [`metabolic.md`](formulas/metabolic.md). Full published numbers: `js/data/coefficients.js`.
